# noot-hud

This is a custom HUD for Team Fortress 2 designed for use in competitive play. The intend behind this HUD is to reduce
clutter and improve visibility of relevant information without making aesthetical sacrifices.

I started making this in 2001 without proper version control. At the time I have only focussed on making the design
work for the core game modes. Since then I created this git repository, but only made infrequent minor changes, so much
of it is still untouched, such as the menus or fringe game modes like MvM and Passtime.
